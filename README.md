# 걱정 나무 (Worry Tree)

걱정을 나무에 괴물로 매달아 두고, 따뜻한 위로의 말을 적어 떠나보내는 웹 앱입니다.
만든 나무는 링크나 QR 코드로 친구에게 보내 대신 위로해 달라고 부탁할 수 있습니다.

**서버가 없습니다.** 걱정은 어디에도 저장되지 않고, 공유 링크 자체에 압축되어 담깁니다.
그래서 정적 호스팅(무료)만으로 운영할 수 있고 운영비가 들지 않습니다.

## 실행하기

```bash
npm install
npm run dev        # http://localhost:3000
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | `dist/` 에 배포용 파일 생성 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run typecheck` | 타입 검사 |
| `npm run tree -- <이미지>` | 나무 이미지 최적화 후 적용 |

## 나무 이미지 교체하기

기본값은 코드에 들어 있는 SVG 나무라 외부 요청이 전혀 없습니다.
직접 만든 그림으로 바꾸려면 한 줄이면 됩니다.

```bash
npm run tree -- ~/Downloads/내가만든나무.png
```

`assets/tree.webp` 로 최적화되어 저장되고, 앱이 자동으로 그 파일을 씁니다.
**코드는 고칠 필요가 없습니다.** 되돌리려면 `assets/tree.webp` 를 지우면 기본 SVG로 돌아갑니다.

### 배경이 흰색이라면 (AI로 만든 그림은 대부분 그렇습니다)

투명 배경이 아니면 하늘색 위에 **흰 사각형**이 그대로 보입니다.
`--remove-white` 를 붙이면 흰 배경을 투명하게 바꿔줍니다.

```bash
npm run tree -- ./tree.png --remove-white
```

배경을 지운 뒤 남는 여백까지 정리하려면 `--trim` 을 함께 씁니다.

```bash
npm run tree -- ./tree.png --remove-white --trim
```

투명 배경이 아닐 경우 스크립트가 경고를 띄우니, 그때 다시 실행하면 됩니다.

### 어떤 비율이든 알아서 맞춥니다

무대(나무와 괴물이 공유하는 좌표계)는 **그림의 비율을 그대로 따릅니다.**
`npm run tree` 가 그림의 비율과 **나뭇잎이 덮는 범위를 자동으로 찾아**
`assets/tree.meta.json` 에 적어두고, 앱이 그 값을 읽습니다.
그래서 세로 그림이든 가로 그림이든 코드를 고칠 필요가 없습니다.

자동 감지가 어긋나면 직접 지정할 수 있습니다.

```bash
# 나뭇잎 범위를 %로 직접 지정 (위,아래,왼쪽,오른쪽)
npm run tree -- ./tree.png --canopy 12,68,24,76
```

### 좁은 화면에서는 나무가 화면 밖으로 넘칩니다

휴대폰처럼 세로로 긴 화면에서 가로로 넓은 나무를 통째로 넣으려 하면, 나무가
아래쪽에 납작하게 깔려 화면이 휑해집니다. 그래서 이 앱은 **나무를 줄이지 않고
크게 키워 좌우로 넘치게** 둡니다. 잘려도 되는 건 나무뿐입니다.

눌러야 하는 걱정 괴물은 절대 잘리면 안 되므로, 나무가 넘치는 만큼 괴물이
매달리는 가로 범위를 안쪽으로 좁힙니다(`--canopy-squeeze`). 보이는 나뭇잎
위에 고르게 퍼지므로 어색하지 않고, 어떤 화면에서도 모든 괴물을 누를 수 있습니다.

| 화면 | 나무 크기 | 화면 세로 채움 | 화면 밖 괴물 |
| --- | --- | --- | --- |
| 데스크톱 1440×900 | 1600×900 | 100% | 0 |
| 태블릿 820×1180 | 2098×1180 | 100% | 0 |
| 휴대폰 390×844 | 1073×603 | 71% | 0 |
| 작은 휴대폰 360×640 | 990×557 | 87% | 0 |

너무 키우면 나무 윤곽이 사라져 잎사귀 벽처럼 보이므로, 화면 폭의 2.75배에서
멈춥니다 (`types.ts` 의 `MAX_STAGE_OVERFLOW`).

### 그림 만들 때 권장 규격

| 항목 | 권장값 |
| --- | --- |
| 크기 | **1920 × 1080 px** 안팎 (비율은 자유) |
| 형식 | 배경이 **투명한 PNG 또는 WebP** |
| 최소 | 1200 px 이상 (긴 변 기준) |

크게 만드셔도 됩니다 — 스크립트가 긴 변 1920px으로 줄이고 WebP로 바꿉니다
(실측: 1920×1080 WebP 149KB → **97KB**, 원본과 육안 구별 불가).

**구도**: 나뭇잎은 그림 가운데에 넓게, 줄기는 아래쪽 가운데에서 맨 아래까지 닿게
그려주세요. 좌우 가장자리는 좁은 화면에서 잘리므로 중요한 요소를 두지 마세요.
괴물은 나뭇잎 타원 안에 매달리되 **줄기 부분은 알아서 피합니다.**

## 배포하기

빌드 결과물은 **경로에 의존하지 않습니다**(`base: './'`). 하위 경로에 올려도
그대로 동작하므로 별도 설정이 필요 없습니다.

```bash
npm run build     # dist/ 를 통째로 올리면 끝
```

- **GitHub Pages** — `dist/` 를 `gh-pages` 브랜치에 올리거나 Actions로 배포
- **Cloudflare Pages / Netlify / Vercel** — 빌드 명령 `npm run build`, 출력 폴더 `dist`

셋 다 개인 프로젝트 규모에서는 무료입니다. 서버도, 데이터베이스도, API 키도 필요 없습니다.

## 공유 링크에 대해

걱정 내용은 압축되어 **링크 주소 안에** 들어갑니다. 서버에 저장되지 않는 대신,
**링크를 가진 사람은 누구나 내용을 볼 수 있습니다.** 링크는 브라우저 방문 기록이나
메신저 미리보기에도 남을 수 있으니 믿을 수 있는 사람에게만 보내주세요.
(앱 안에도 같은 안내가 표시됩니다.)

걱정이 많아지면 링크가 길어지고 QR 코드가 촘촘해집니다. 앱이 자동으로
오류정정 수준을 조절하고, 스캔이 어려울 정도가 되면 링크 복사를 안내합니다.
